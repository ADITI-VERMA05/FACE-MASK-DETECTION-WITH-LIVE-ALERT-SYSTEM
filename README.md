# FACE-MASK-DETECTION-WITH-LIVE-ALERT-SYSTEM
Face Mask Detection with Live Alert System is a real-time computer vision application that detects whether a person is wearing a mask using a webcam feed and triggers an alert for violations.


# Dataset
https://www.kaggle.com/datasets/omkargurav/face-mask-dataset


## How to run

```bash
conda create -p venv python==3.10 -y
```

```bash
conda activate venv/
```

```bash
pip install -r requirements.txt
```

```bash
python app.py
```
